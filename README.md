# Exploring-AI-and-AI-Tools-Workshop

The difference between a normal prompt and a COSTAR framework prompt is that a COSTAR prompt is a structured prompt that combines six elements:

Context: Background information.
Objective: What you want the AI to do.
Style: The format or style of the output.
Tone: The emotional quality or manner of the response.
Audience: Who the output is intended for.
Response: The specific format of the final response.
In contrast, a normal prompt may not provide all of this information, 
which can lead to a trial-and-error process, also known as "meta prompting", to refine the prompt and get a satisfactory result.
 A COSTAR prompt provides more clarity and specificity, allowing the AI to produce a more accurate and relevant response.
